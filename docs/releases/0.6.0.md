# Calx VM 0.6.0 release candidate / 发布候选范围

Status: unreleased candidate on main. Tracking: [#75](https://github.com/calcit-lang/calx-vm/issues/75),
parent [#61](https://github.com/calcit-lang/calx-vm/issues/61).

## English

The 0.6.0 candidate corrects the historical parser alias between Tag and String. `|text` is
`Calx::Str`, while `:name` is `Calx::Tag`; their strict types are `str` and `tag`. Display keeps
the source prefixes so CLI output and value round trips are unambiguous.

Tag is admitted anywhere the strict concrete value domain is admitted: parameters/results,
locals, globals, constants, block/loop/if signatures, named entries, builder declarations, and
typed host imports. Validator, entry, and host-result guards reject Str/Tag mismatches before or
at the relevant boundary. The encoded `CalxType::Tag` discriminant is appended after existing
variants so earlier discriminants are not renumbered.

This release does not add Symbol, Tag/String coercion, equality, hashing, ordering, interning,
dispatch, enum/match semantics, collections, Nil, Dynamic, a scheduler, or a VM pool. Calcit must
continue using calx_vm 0.5.1 until 0.6.0 is published and verified; local path overrides are only
development evidence.

Before release, the exact candidate commit must pass formatting, all tests, all publish-workflow
demos, Clippy with warnings denied, a crates.io-style package build, latest-head review, and exact-main
CI. The tag, GitHub Release, crates.io version, and downstream pin must name the same published version.

本版本不增加 Symbol、Tag/String coercion、相等、hash、排序、interning、dispatch、enum/match、
