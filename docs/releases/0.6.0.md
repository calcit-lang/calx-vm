# Calx VM 0.6.0 release scope / 0.6.0 发布范围

Status: published. The [GitHub Release](https://github.com/calcit-lang/calx-vm/releases/tag/0.6.0)
and crates.io are authoritative for availability. The annotated tag, exact-main Test, and successful
[publish workflow](https://github.com/calcit-lang/calx-vm/actions/runs/34672441340) identify commit
`785015f637a6a94d0f9988065e29214d1c035fa7`. This release tracks
[#75](https://github.com/calcit-lang/calx-vm/issues/75), contains the strict Tag/Str identity split
merged in [#77](https://github.com/calcit-lang/calx-vm/pull/77) with the

[#61](https://github.com/calcit-lang/calx-vm/issues/61).

## English

The 0.6.0 candidate corrects the historical parser alias between Tag and String. `|text` is
`Calx::Str`, while `:name` is `Calx::Tag`; their strict types are `str` and `tag`. Display keeps
the source prefixes so CLI output and value round trips are unambiguous.

Tag is admitted anywhere the strict concrete value domain is admitted: parameters/results,
locals, globals, constants, block/loop/if signatures, named entries, builder declarations, and
typed host imports. Validator, entry, and host-result guards reject Str/Tag mismatches before or
at the relevant boundary. The encoded `CalxType::Tag` discriminant is appended after existing
variants so earlier discriminants are not renumbered.

This release does not add Symbol, Tag/String coercion, equality, hashing, ordering, interning,
dispatch, enum/match semantics, collections, Nil, Dynamic, a scheduler, or a VM pool. Calcit adopts
the exact published 0.6.0 by pinning `calx_vm = "=0.6.0"`; local path overrides are only development
evidence.

追加在已有 variants 之后，不重排历史 discriminants。

本版本不增加 Symbol、Tag/String coercion、相等、hash、排序、interning、dispatch、enum/match、
collections、Nil、Dynamic、scheduler 或 VM pool。Calcit 通过固定 `calx_vm = "=0.6.0"` 采用已发布的
