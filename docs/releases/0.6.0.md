# Calx VM 0.6.0 release candidate / 发布候选范围

Status: release candidate. GitHub Releases and crates.io remain authoritative for availability.
Tracking: [#75](https://github.com/calcit-lang/calx-vm/issues/75),
parent [#61](https://github.com/calcit-lang/calx-vm/issues/61).

## English

The 0.6.0 candidate corrects the historical parser alias between Tag and String. `|text` is
`Calx::Str`, while `:name` is `Calx::Tag`; their strict types are `str` and `tag`. Display keeps
the source prefixes so CLI output and value round trips are unambiguous.

Tag is admitted anywhere the strict concrete value domain is admitted: parameters/results,
locals, globals, constants, block/loop/if signatures, named entries, builder declarations, and
typed host imports. Validator, entry, and host-result guards reject Str/Tag mismatches before or
at the relevant boundary. The encoded `CalxType::Tag` discriminant is appended after existing
variants so earlier discriminants are not renumbered.

This release does not add Symbol, Tag/String coercion, equality, hashing, ordering, interning,
dispatch, enum/match semantics, collections, Nil, Dynamic, a scheduler, or a VM pool. Calcit must
continue using calx_vm 0.5.1 until 0.6.0 is published and verified; local path overrides are only
development evidence.

### Release order

1. Pass formatting, all tests, all publish-workflow demos, Clippy with warnings denied, a
   crates.io-style package build, latest-head review, and required CI before merging this release PR.
2. Verify required Actions on the exact merged main SHA. Point the annotated `0.6.0` tag and GitHub
   Release at that same SHA.
3. Confirm the publish workflow succeeds and crates.io exposes 0.6.0.
4. Update Calcit to the exact `calx_vm = "=0.6.0"` dependency and add compiler-owned Tag lowering
   coverage before closing #75.

## 中文

0.6.0 候选版本修正历史上的 Tag/String parser 别名：`|text` 为 `Calx::Str`，`:name` 为
`Calx::Tag`，对应 strict type 分别是 `str` 与 `tag`。Display 保留源码前缀，使 CLI 输出与
value round trip 无歧义。

Tag 可进入 strict concrete value domain 的全部位置：参数/结果、local、global、constant、
block/loop/if 签名、具名入口、builder declaration 与 typed host import。validator、entry 与
host-result 守卫会在执行前或准确边界拒绝 Str/Tag 错配。`CalxType::Tag` 的编码 discriminant
追加在已有 variants 之后，不重排历史 discriminants。

本版本不增加 Symbol、Tag/String coercion、相等、hash、排序、interning、dispatch、enum/match、
collections、Nil、Dynamic、scheduler 或 VM pool。0.6.0 正式发布并验证前，Calcit 继续依赖
calx_vm 0.5.1；本地 path override 只能作为开发证据。

3. 确认 publish workflow 成功，crates.io 可读取 0.6.0。
