# 冻结严格 F64Buffer ABI / Freeze the strict F64Buffer ABI

## 中文

- 将 #50 拆分为 RFC、VM/validator 与 Calcit adapter/benchmark 三个依赖明确的阶段，并以 #51 启动 RFC。
- 冻结不可变 `F64Buffer` concrete type、`Rc<[f64]>` 单线程共享 backing、O(1) clone 与显式 share/adopt/copy 成本。
- 首版 strict boundary 只允许 function/local/import/block，拒绝 global、List、Nil、Dynamic、nullable element 与 borrowed lifetime。
- 定义 `f64-buffer.len`、`f64.to-i64-index`、`f64-buffer.get`：Calcit Number 仍是 F64，只有显式 checked conversion 能产生 I64 index。
- 非法 conversion 与越界统一 trap，不返回 Nil、Option、默认值，也不在 VM trap 后重跑 Calcit。
- typed-buffer kernel 使用 `calcit-calx-kernel/2`，并要求 source artifact、per-use buffer input 与 host binding 分离，以兼容 hot reload 和后续 compile cache。

## English

- Split #50 into dependency-ordered RFC, VM/validator, and Calcit adapter/benchmark stages, starting the RFC in #51.
- Freeze an immutable concrete `F64Buffer`, single-threaded shared `Rc<[f64]>` backing, O(1) clones, and explicit share/adopt/copy costs.
- Initially allow the strict type only at function/local/import/block boundaries while rejecting globals, Lists, Nil, Dynamic, nullable elements, and borrowed lifetimes.
- Define `f64-buffer.len`, `f64.to-i64-index`, and `f64-buffer.get`: Calcit Numbers remain F64 and only an explicit checked conversion produces an I64 index.
- Invalid conversions and bounds failures trap without Nil, Option, default values, or a Calcit retry after VM execution begins.
- Require `calcit-calx-kernel/2` for typed-buffer kernels and keep immutable source artifacts separate from per-use buffers and host bindings for hot reload and later compile caching.
