# 准备发布 0.3.0 / Prepare release 0.3.0

## 中文

- 将稳定版本从 0.2.2 提升到 0.3.0，明确反映 strict typed program/runtime API 的兼容边界变化。
- 该版本汇总 typed operand/control validation、source-aware diagnostics、typed local/global/import contracts、strict runtime integration、F64 comparisons 与 `ProgramBuilder`。
- `ProgramBuilder` 的稳定发布解除 Calcit translator 下一阶段对 git revision 的依赖阻塞。
- 发布前验证与 workflow 对齐：格式、全部测试、全部 demos、strict Clippy 和 `cargo package`。

## English

- Raise the stable version from 0.2.2 to 0.3.0 to reflect the compatibility boundary introduced by the strict typed program/runtime APIs.
- This release combines typed operand/control validation, source-aware diagnostics, typed local/global/import contracts, strict runtime integration, F64 comparisons, and `ProgramBuilder`.
- A stable `ProgramBuilder` release unblocks the next Calcit translator slice without relying on a Git revision.
- Align pre-release verification with the publish workflow: formatting, all tests, all demos, strict Clippy, and `cargo package`.
