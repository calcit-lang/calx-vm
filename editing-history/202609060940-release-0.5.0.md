# Prepare the 0.5.0 compatibility boundary

## 中文

strict 准入较 0.4.0 收紧，按 0.5.0 发布候选追踪，包含已合并的 trace、值域封闭和
尾调 locals 复用。同步 crate 描述/仓库地址、迁移与 roadmap 的已完成/待发布状态，
不删除延期设计。raw 性能证据只链接 standalone。消费者必须等正式发布后采用精确
版本；发布/消费链完成前不关闭 #60。此次不修改 VM 执行机制或依赖集合。

## English

Prepare 0.5.0 for stricter admission than 0.4.0, grouping merged tracing, strict
closure and tail-call reuse. Refresh crate metadata, migration and roadmap status
without dropping deferred designs. Link standalone performance evidence only.
Consumers adopt exact versions after publication; keep #60 open for that chain.
No VM execution or dependency-set changes are included.
