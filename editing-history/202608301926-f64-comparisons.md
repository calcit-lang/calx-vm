# F64 comparison instructions

## 修改概要

- 增加 `f.eq/ne/lt/le/gt/ge` 六个 source opcodes，以及对应的 `CalxSyntax`/`CalxInstr` variants。
- validator 固定检查 `F64 F64 -> Bool`，不经过 Dynamic 或现有 `Add/Mul` overload。
- interpreter 复用单一 F64 comparison helper，并返回轻量 source-aware `CalxError`。
- 增加六条 opcode 正常路径、每条错误 operand type、手工 lowered runtime 防御、CLI
  check/explain 和 IEEE-754 边界回归。
- 更新 instruction set/matrix 与 RFC 0003；同步修正文档中 legacy local/global 仍以 nil 初始化的
  过时说明。

## 关键知识点

- Calcit `Number` 是 `f64`，range/Fibonacci translator 的数值条件不能改用 I64 comparison。
- Rust `f64` comparisons 与 Calcit 0.13.66 原生抽样一致：NaN 自身不等、NaN ordering 为 false、
  Infinity 有序、`0.0 == -0.0`。
- comparison 使用独立 opcode，既不扩大 `Add/Mul` legacy overload，也不改变 Calx legacy
  truthiness；Calcit frontend 仍须静态证明条件为 Bool。
- F64 comparison helper 在原 stack left slot 写回 Bool，不分配 Dynamic contract 或 nil sentinel。
