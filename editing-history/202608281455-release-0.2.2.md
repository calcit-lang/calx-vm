# 发布 0.2.2 / Release 0.2.2

## 中文

- 发布 M0 指令语义与宿主安全基线、类型化 operand/control stack validator。
- 新增 `check` 与 `explain` 教学命令和结构化诊断。
- 将 `CalxError` VM snapshot 改为可选 boxed payload，缩小公开 `Result` 的 inline error 大小。

## English

- Release the M0 instruction-semantics and host-safety baseline plus the typed operand/control-stack validator.
- Add the `check` and `explain` teaching commands with structured diagnostics.
- Move the `CalxError` VM snapshot into an optional boxed payload, reducing the inline error size of public `Result` values.
