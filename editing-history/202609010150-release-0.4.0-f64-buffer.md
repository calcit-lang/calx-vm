# 发布 0.4.0：F64Buffer stable dependency / Release 0.4.0: stable F64Buffer dependency

## 中文

Calcit 到 Calx 的严格 F64Buffer vertical slice 只能依赖 crates.io 的稳定 `calx_vm`，
不能用 git revision 绕过发布边界。0.4.0 因此将已经在 main 完成的 immutable `F64Buffer`
value、typed boundary、checked index/bounds trap 与 `ProgramBuilder` helpers 作为稳定依赖发布。

验证必须覆盖 `cargo fmt --check`、`cargo test`、publish workflow 的 `./try.sh`、strict clippy
及 `cargo package --allow-dirty`。发布后 Calcit 才能将依赖从 0.3.0 提升到 0.4.0，并继续
ABI `/2` source-backed kernel；不使用 git dependency 或临时 List/Nil/Dynamic bridge。

## English

The strict Calcit-to-Calx F64Buffer vertical slice must depend on a stable crates.io
`calx_vm` release, not bypass the release boundary through a git revision. Version 0.4.0
therefore publishes the immutable `F64Buffer` value, typed boundary, checked index and
bounds traps, and `ProgramBuilder` helpers already completed on main.

Verification covers `cargo fmt --check`, `cargo test`, the publish workflow's `./try.sh`,
strict clippy, and `cargo package --allow-dirty`. Only after publication may Calcit raise
its dependency from 0.3.0 to 0.4.0 and continue the ABI `/2` source-backed kernel, without
a git dependency or temporary List/Nil/Dynamic bridge.
